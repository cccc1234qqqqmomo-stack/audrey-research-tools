Audrey Research Tools

Personal Product Research Application

About

Audrey Research Tools is a personal project for researching publicly available product listing information on online marketplaces.

Planned Features

  • Product listing research
  • Product price comparison
  • Keyword and tag analysis
  • Market trend research

API Usage

The project intends to use the official Etsy API in accordance with applicable developer policies.

Access

Designed for personal research use. Not currently offered as a public service.
